# Grade Calculator & Student Report Card

A simple Python project that started as a Grade Calculator and was upgraded into a Student Report Card.

## Features

- Enter student name and roll number
- Enter marks for multiple subjects
- Calculate total marks
- Calculate average marks
- Calculate grade
- Check Pass/Fail
- Display student report card

## Concepts Used

- Variables
- Input/Output
- Lists
- Dictionaries
- For Loops
- If-Elif-Else
- Basic calculations

## Project Files

- `grade_calculator.py` - Original grade calculator
- `student_report_card.py` - Upgraded report card

## Goal

To practice Python basics by building and upgrading a simple real-world project.
